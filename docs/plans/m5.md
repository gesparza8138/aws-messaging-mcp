# M5 plan — hardening and subsystem documentation

Status: **draft — awaiting owner approval (gate M5-G1)**. The final
milestone: no new tools. Scope per [PRD](../PRD.md) §16 M5 (dashboard,
runbooks, drills, docs pass) plus the owner's 2026-08-24 addition: three
dedicated subsystem documents. Exit criteria: every runbook executed once
successfully; every alarm has fired at least once in a drill or synthetic
test; the three subsystem docs exist and pass the docs CI.

## 1. Scope

### 1.1 Observability (infra)

- **Alarms** (×4, SNS email to `AlarmEmail`): Lambda errors ≥ 1 in 5 min;
  Lambda throttles ≥ 1; CloudFront 5xx rate > 5 % over 15 min (4xx is
  normal traffic here — every unauthenticated probe is a 401/403, so the
  PRD's "4xx rate" becomes a 5xx alarm, noted as an M5 finding); files
  `BytesDownloaded` > 80 GB/month (R10, prod only).
- **Budget**: `AWS::Budgets::Budget` on actual spend — $10/month threshold
  with an SNS email (per-service scoping to SES+EUM proved coarser than the
  account-level number at this scale; finding to record).
- **Dashboard**: sends per tool (SES/EUM event counts), Lambda errors +
  duration p95, CloudFront requests/5xx, DynamoDB throttles.
- **`ReservedConcurrency=5`** in both params files — **only if** the Lambda
  quota request has been approved by execution time; otherwise it stays a
  checked-off pending item and ships in a patch release later.

### 1.2 Runbooks and drills (exit: each executed once)

- **`docs/runbooks/incident.md`** (new): runaway-sends containment —
  empty the edge allow-list (`update-my-ip.sh --ip 255.255.255.255`-style
  lockout), `ReservedConcurrency=0`, revoke Cognito refresh tokens, verify
  sends stop, then restore. Drilled on **dev only**, timed, results recorded
  in the runbook.
- **Rotation drill**: run `rotate-secret` (both halves) and
  `rotate-signing-key` on dev for real; confirm the deploy + e2e stay green
  and old break-glass/signed URLs die.
- **Auth-recovery walkthrough**: validate `auth-recovery.md` steps against
  the current Cognito/hosted-bridge reality; fix drift.

### 1.3 Subsystem documentation (owner request, 2026-08-24)

Three dedicated documents, each linked from the README and PRD §12:

| Doc | Contents |
| --- | --- |
| **`docs/server.md`** — the Lambda and every tool | The single `bootstrap` binary and its three entry paths (Function URL HTTP, scheduler tasks, local `--listen`); the request pipeline (edge allow-list → origin secret → bearer auth → scope → guardrails → AWS call); per-tool walkthroughs for all 14 tools: scope, guardrails consulted, server-injected fields, `DryRun` shape, failure modes; how tool registration gates on configuration (SES always, EUM on the origination number, files on bucket+key); the shared pieces (rate limiter, event trails, signing) |
| **`docs/cicd.md`** — pipeline and security measures | Every check on the road to prod: the six required PR checks (gofmt/vet/golangci-lint + pre-commit; `go test -race` with the 90 %/100 % coverage floors; gosec/govulncheck/gitleaks/dependency-review + CodeQL; cfn-lint/checkov/cfn_nag; markdownlint/lychee/tool-docs drift; commitlint), branch protections (signed commits, squash-only, no direct push), OIDC deploys with ID-pinned subjects and no long-lived AWS keys, the change-set preview/execute split, environment gates (prod reviewer + wait timer + tag-only), the e2e job's runner self-registration, and the secrets story (what lives in SSM vs GitHub vs nowhere) |
| **`docs/infrastructure.md`** — IaC and how it deploys | The five stacks (bootstrap, edge, root-dns, ses-domain, eum, app ×2 stages) and why each exists at its layer; what is pure CFN vs the few scripted edges (Free-plan enrolment, allow-list republish); parameter flow (params files → SSM-fed NoEcho values → workflow-resolved values like the PEM and phone ARN); conditional resources (`HasFilesKey`, `HasEumPhone`) and why deploy order never matters; DeletionPolicy choices (zones, phone number); the deploy roles' least-privilege model and the CFN service role |

`docs/architecture.md` stays the high-level map and gains pointers to the
three; overlap is resolved by moving detail out of it, not duplicating.

## 4. Risks

- Alarm thresholds at personal-scale traffic are guesswork; they ship
  conservative and get tuned from the first month's data.
- The incident drill intentionally takes dev down for minutes; prod is
  never touched by drills.
- `ReservedConcurrency` stays parked if AWS hasn't granted the quota —
  not a release blocker.
